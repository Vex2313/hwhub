# HW Hub — Автономный игровой хаб для GitHub Pages

Легковесный, быстрый и полностью автономный хаб с играми, оптимизированный под слабые школьные ПК и защищённый от блокировок фильтрами (SkyDNS и др.).

## ⚡ Особенности
- **100% Self-Hosted**: Никаких внешних iframe и сторонних доменов. Все игры и ассеты хранятся прямо в репозитории.
- **Школьный стелс (Anti-Учитель)**:
  - **Tab Cloak**: Мгновенная смена заголовка и фавикона вкладки (*Дневник.ру*, *ЯКласс*, *Решу ЕГЭ*, *Google Документы*, *Википедия*).
  - **Panic Button (Кнопка паники)**: Нажатие горячей клавиши (`\` по умолчанию) переключает экран на фейковый код решения задачи по информатике (VS Code) или перенаправляет на учебный сайт.
  - **about:blank Launcher**: Открытие любой игры внутри пустой вкладки `about:blank`, не оставляющей следов в истории браузера.
- **Быстродействие**: Чистый HTML5/CSS/JS без тяжелых фреймворков и «нейрослопа». 0 мс задержки ввода, летает на любом старом железе.

## 🚀 Как задеплоить на GitHub Pages

1. **Инициализируйте Git и сделайте коммит**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of HW Hub"
   git branch -M main
   ```

2. **Создайте новый репозиторий на GitHub** (например, с именем `hwhub`).

3. **Свяжите локальный репозиторий с GitHub и запушьте**:
   ```bash
   git remote add origin https://github.com/<ВАШ_НИК>/hwhub.git
   git push -u origin main
   ```

4. **Включите GitHub Pages**:
   - Перейдите в репозитории: **Settings** → **Pages**.
   - В разделе **Build and deployment** выберите:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main`, папка `/ (root)`
   - Нажмите **Save**.
   - Через 1–2 минуты сайт станет доступен по адресу:
     `https://<ВАШ_НИК>.github.io/hwhub/`

## ➕ Как добавить новую игру

1. Создайте папку в `games/<id_игры>/` и положите туда веб-версию игры (файл запуска должен называться `index.html`).
2. Откройте файл `games.json` и добавьте карточку игры:
   ```json
   {
     "id": "mygame",
     "title": "Моя Новая Игра",
     "category": "arcade",
     "tags": ["Аркада", "Хит"],
     "desc": "Краткое описание игры.",
     "path": "games/mygame/index.html",
     "thumb": "games/mygame/thumb.png",
     "size": "< 5 MB",
     "offline": true
   }
   ```
3. Сделайте `git add .`, `git commit -m "Add mygame"` и `git push`. Игра появится в хабе автоматически!
